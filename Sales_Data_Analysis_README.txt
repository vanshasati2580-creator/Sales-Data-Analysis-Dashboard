# Sales Performance Dashboard using Excel and Power BI

## Project Objective
Analyze sales data to identify:
- Total Sales
- Top Products
- Monthly Revenue Trends
- Top Cities by Sales

## Tools Used
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Visualization
- Dashboard Design

## Dataset
This project uses 300 synthetic sales records with these columns:
Order ID, Order Date, Month, City, Region, Category, Product, Quantity, Unit Price, Discount %, Sales, Profit, Payment Mode, Customer Segment.

## Key Analysis
1. Total sales and profit were calculated using Excel formulas.
2. Monthly revenue was analyzed using date-based SUMIFS formulas.
3. Top products were ranked by revenue.
4. Top cities were ranked by sales contribution.
5. Power BI dashboard steps are included inside the workbook.

## Dashboard Pages
- Excel Dashboard
- Monthly Analysis
- Product Analysis
- City Analysis
- Power BI Guide
